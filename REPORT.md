## Ход работы

В рамках лабораторной работы подготовлен проект с файлами `package.json` и `app.js`. Приложение использует встроенный модуль `http` и не требует сторонних зависимостей. Для проверки запуска в консоль выводится сообщение `Node.js is working!`.

Сервер создан с помощью `http.createServer()` и прослушивает порт `3000`. Объект `req` содержит сведения о запросе, а `res` используется для формирования ответа. Выбор обработчика выполняется по HTTP-методу `req.method` и адресу `req.url`. Отправка ответа завершается вызовом `res.end()`.

В приложении предусмотрены следующие GET-маршруты:

| Маршрут | Содержание ответа |
| --- | --- |
| `/` | Текст `Home page` |
| `/about` | Текст `About page` |
| `/student` | HTML-страница с именем, фамилией, группой и специальностью студента |
| `/api/student` | Данные студента в формате JSON и счётчик обращений к этому маршруту |
| `/time` | Текущее локальное время, полученное через `Date` и `toLocaleTimeString()` |
| `/courses` | JSON-массив из пяти учебных дисциплин |
| `/myURL` | Собственный маршрут, предназначенный для возврата JSON с данными автомобиля |

Для JSON-ответов устанавливается заголовок `Content-Type: application/json`, а данные преобразуются в строку методом `JSON.stringify()`. Для HTML-ответов указывается `text/html; charset=utf-8`.

В самостоятельной части добавлены сведения о дисциплинах: название, преподаватель, количество кредитов, идентификатор и код. Также подготовлены данные автомобиля для собственного маршрута и реализован счётчик `numberReq`, который увеличивается при каждом обращении к `/api/student` и хранится в памяти до перезапуска приложения.

## Запуск приложения

Из папки `lab_1` сервер запускается командой:

```bash
node app.js
```

После запуска маршруты доступны по адресу `http://localhost:3000` с соответствующим путём, например `http://localhost:3000/student`.

## Замечания по текущей версии

При анализе исходного кода выявлены следующие расхождения с заданием:

- Дисциплины доступны по пути `/courses`, тогда как в задании указан `/api/courses`.
- Маршрут `/time` возвращает только время, без даты. Логирование каждого запроса с методом, URL, датой и временем отсутствует.
- В обработчике `/myURL` указан `req.end()` вместо `res.end()`, поэтому отправка ответа завершится ошибкой.
- Для неизвестного адреса используется `res.statusCode(404)` вместо присваивания `res.statusCode = 404`. Из-за этого корректный ответ со статусом 404 не отправляется.
